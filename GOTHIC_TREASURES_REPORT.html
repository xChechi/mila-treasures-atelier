1. Project Overview

Gothic Treasures is a custom ecommerce platform for selling handcrafted gothic home wall decor. Each product is a one-of-a-kind piece handmade in Bulgaria and shipped to the USA. The site features a dark, atmospheric gothic aesthetic with elegant animations and a full shopping experience.

The frontend is production-ready with all customer-facing pages, an admin dashboard, blog, and comprehensive SEO. The backend phase (database, payments, authentication) is planned but blocked on account creation.

6. Completed Features — Full Breakdown

Core E-Commerce

  • Product catalog (8 products, 4 categories) with search, category filter, sorting (price, name)
  • Product detail pages — image gallery, specs (material, dimensions, weight), description, reviews, related products
  • Shopping cart — add/remove, persistent across sessions, order summary with promo codes & gift wrapping
  • Guest checkout — US shipping address form with validation, mock order confirmation
  • Order tracking — 4-stage gothic timeline (Confirmed → Crafting → Shipped → Delivered) with animated pulse
  • Promo code system — 3 mock codes (10%, 15%, 20% off), real-time discount calculation
  • Gift wrapping — $12 add-on with optional personal message (200 chars)
  • Print invoice — clean B&W invoice layout via browser print dialog

User Experience

  • Product Quick View Modal — preview without leaving shop page (image, specs, rating, cart actions)
  • Recently Viewed Products — tracks last 8 viewed, horizontal strip on product detail & shop pages
  • Advanced Filters — price range (dual slider), material dropdown, in-stock toggle, collapsible panel
  • Product Image Zoom / Lightbox — full-screen, scroll zoom (4x), drag pan, keyboard controls
  • Product Badges — New, Bestseller, Limited Edition, Last One tags on cards & Quick View
  • Wishlist / Save for Later — heart icons, localStorage persist, dedicated /wishlist page, navbar badge
  • "CLAIMED" overlay on sold-out products
  • Recently Sold Ticker — animated notification cycling sold items
  • Size Reference — wall-scale dimension visualizer
  • Currency preview toggle — USD/EUR/GBP with approximate conversion rates
  • Social sharing — Pinterest Pin It, copy link, native Web Share API

Content & Marketing

  • 5-article blog/journal with categories (Workshop, Culture, Inspiration, Behind the Scenes)
  • Newsletter signup with VIP tier selection (standard vs 48-hour early access)
  • Brand story & customer testimonials (4 reviews on landing page)
  • About page — origin story, craft features, shipping & returns info
  • Contact page — form with validation, FAQ accordion (4 items)

Admin Dashboard

  • Dashboard with 4 stats cards (products, stock, sold out, revenue) + recent orders table
  • Products CRUD — table with image thumbnails, add/edit modal, delete confirmation
  • Orders table — expandable rows, status badges (Processing/Shipped/Delivered)
  • Analytics — revenue area chart, daily visitors, top products bar chart, category donut, conversion funnel with drop-off %
  • Settings page with Supabase/Stripe integration placeholders
  • Admin layout hides public nav/footer, mobile sidebar with hamburger

SEO & Technical

  • Per-page metadata with title template (%s — Gothic Treasures)
  • Dynamic generateMetadata() for product + category pages with OG/Twitter cards
  • Programmatic robots.txt + sitemap.xml
  • JSON-LD structured data — Organization, WebSite, Product, BlogPosting, AggregateRating
  • Custom gothic 404 page ("Lost in the Shadows")
  • OG image for social sharing, canonical URLs, noindex on cart/checkout
  • Page transitions — Framer Motion fade + upward slide
  • Loading skeletons with gothic frame corners
  • Accessibility — skip-to-content, focus-visible gold outlines, ARIA labels
  • Cart persistence via Zustand + localStorage
  • Mobile responsive with hamburger nav, horizontal scroll filters
  • Custom cursor (golden cross), grain overlay, scroll progress bar, back-to-top button

Database Schema (10 tables)

  • categories — name, slug, description, image
  • products — name, slug, price, description, category_id, in_stock, featured, badge, dimensions, material, weight
  • product_images — product_id, url, sort_order
  • reviews — product_id, author, location, rating, text, verified
  • orders — order_number, customer_name, email, total, status, shipping_address, promo_code, gift_wrap, gift_message
  • order_items — order_id, product_id, price
  • contact_submissions — name, email, subject, message
  • newsletter_subscribers — email, tier (standard/vip)
  • admin_users — email, password_hash, role
  • site_settings — key, value (store config)

Launch Cost

$0/month — All free tiers: Supabase Free, Stripe (pay-per-transaction only), Vercel Hobby, Resend Free (100 emails/day), Cloudflare DNS (free). Only cost: domain (~$10-15/year).
